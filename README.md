# CampusEats

CampusEats is a campus-focused food management project designed to make
food discovery and ordering easier for students.

## Project Overview

This repository contains documentation and practical networking tasks
completed as part of the project work.

## Contents

- `http-log.md` - HTTP request and response logs using curl
- `network-analysis.md` - Browser DevTools network analysis
- `docs/` - Additional project documentation
- Screenshots - Evidence of completed tasks

## Network Analysis

The project includes analysis of:
- HTTP status codes
- Content-Type headers
- API requests and responses
- Browser Network waterfall
- Request count and transferred resources
